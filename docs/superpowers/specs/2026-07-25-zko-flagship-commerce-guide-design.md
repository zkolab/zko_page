# 苍虬旗舰官网、商城与使用说明改版设计

## 目标

将现有单页产品站升级为三页面静态品牌站，在不复制大疆品牌资产、宣传图片或页面源码的前提下，借鉴其紧凑导航、旗舰产品叙事、全幅章节、清晰购买入口和深色多栏页脚。网站继续部署在 `shenqiqishi/zko_page` 的 GitHub Pages。

## 设计方向

采用用户选择的 A 方案“黑白旗舰叙事”：

- 顶部使用深色、紧凑、吸顶的全站导航，品牌与主要入口保持单行布局。
- 主体以黑、白、浅灰大幅章节交替，减少现有页面持续深色霓虹造成的视觉疲劳。
- 青色作为功能与技术强调色，橙色作为实体按键和购买提示的辅助识别色。
- 动效保持克制：滚动显现、轻微景深位移、数字或状态过渡、吸顶商品购买条；关闭动画或系统启用减少动态效果时，内容仍完全可用。

## 信息架构

### `index.html`：品牌首页

1. 全站导航：`产品`、`商城`、`使用说明`、`下载`，右侧提供“立即购买”。
2. 旗舰首屏：使用自有产品图与“把 AI 工作流握在手里”主张，提供“了解产品”和“立即购买”。
3. 核心能力：4 枚实体宏键、Agent 状态灯、小屏反馈、Profile、演讲光圈。
4. 分镜式产品故事：使用 `12.png`、`14.png`、`15.png` 和发布仓库 README 图片展示宏键、状态、软件与接口。
5. 软件协同：AutoClipboard 界面和 GitHub 下载入口。
6. 麦克风场景：明确大疆麦克风仅为适配/展示配件，不包含在包装内。
7. 商城与使用说明入口。

### `shop.html`：单商品商城

1. 产品吸顶子导航和“立即购买”按钮。
2. 大幅商品首屏与产品图库，使用用户授权的 `12.png`–`15.png`、新上传的接口图和发布仓库自有图片。
3. 颜色预订：默认灰色，可提前沟通预订红色、白色、黑色、紫色。色卡为意向展示，不在站内保存订单。
4. 麦克风适配：重点列出 DJI Mic 一代与 DJI Mic 2 二代，并附官方产品链接；其他型号表述为“可按型号确认或定制适配件”。
5. 包装与交付：手柄、电子资源和说明；麦克风不包含在包装内。
6. 价格、库存和最终规格以闲鱼商品页为准，所有购买按钮跳转到用户提供的闲鱼链接。
7. 不实现站内账号、购物车、支付、库存或订单系统。

### `guide.html`：使用说明

内容以 `Lijinzh/Communist-Manifesto-Releases` README 为事实来源，并提供清晰目录：

1. 五分钟首次使用。
2. 充电、Type-C 数据线与开关。
3. 蓝牙名称 `CommunistKB-XXXX`、首次配对和 `PAIR` / `LINK` / `WAIT` 状态。
4. 三台主机槽位的添加、切换与删除。
5. 波轮、中键、侧面四枚宏按键与 Settings 操作。
6. AutoClipboard 安装、后台运行和 Agent 状态同步说明。
7. CH343 驱动、GitHub 发布仓库和排障入口。
8. 常见问题：找不到蓝牙、已配对但软件未就绪、宏键可用但无 Agent 状态、Type-C 无 COM 端口。

## 导航与页脚

- 三个页面共用相同的品牌导航和响应式移动菜单。
- `下载` 链接统一指向 `https://github.com/Lijinzh/Communist-Manifesto-Releases`。
- `立即购买` 统一指向用户提供的闲鱼商品链接。
- 页脚采用深色多栏结构，分为“产品”“购买与下载”“使用支持”“项目”，不复制大疆栏目和法律文案。

## 素材来源与处理

- 使用当前工作区中的 `12.png`–`15.png`、`4.png`–`5.png`。
- 使用用户新上传的接口说明图，保存为站点自有素材。
- 下载并本地化发布仓库 README 中的 `handle-hero.webp`、`macro-buttons.webp`、`agent-status.webp`、`usb-type-c-interface.jpg`、`workflow.webp`、`autoclipboard-main.webp` 和 `autoclipboard-settings.webp`。
- 图片统一放入 `assets/images/`，转换或压缩为适合网页的 WebP/JPEG，并保留合理分辨率。
- 不下载或复制大疆官网的 Logo、宣传图、视频、字体、脚本或页面源码。

## 交互与可访问性

- 桌面端使用紧凑吸顶导航；移动端使用可关闭、支持 Escape 和焦点恢复的菜单。
- 商城颜色色卡支持鼠标和键盘操作，并显示当前选择与“默认灰色”说明。
- 页面使用语义化标题、地标、图片替代文本和可见焦点。
- 外部链接使用 `target="_blank"` 与 `rel="noopener noreferrer"`。
- `prefers-reduced-motion: reduce` 下关闭非必要动画。

## 验证标准

- `index.html`、`shop.html`、`guide.html` 均可独立打开，导航互通。
- 所有下载入口指向指定 GitHub 仓库，所有购买入口指向指定闲鱼链接。
- 商城包含默认灰色及红、白、黑、紫预订说明，且不显示未经确认的固定价格。
- 使用说明准确覆盖 README 的蓝牙配对、三主机和排障流程。
- 所有本地图片存在、可解码、尺寸合理且不引用大疆官网资产。
- 自动化测试、桌面与移动端视觉检查通过。
- 推送后 GitHub Pages 部署成功，三页面在线可访问且关键链接正确。
