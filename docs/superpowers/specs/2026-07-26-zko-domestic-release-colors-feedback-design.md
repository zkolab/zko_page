# ZKO 国内发布入口、颜色预订与搭配反馈设计

## 目标

在现有三页面静态官网基础上完成一轮小范围增强：为国内用户增加 Gitee 发布入口，把 Gitee 与 GitHub 作为同等地位的正式发布仓库；使用 `figures` 中带编号的新软件截图；明确默认灰色与其他颜色的预订规则；在商城增加指向腾讯文档的搭配建议区域；为后续替换商品图库首张大图准备 GPT Image 2 绘图指令。

## 发布仓库入口

正式发布仓库为：

- Gitee：`https://gitee.com/shan-yujun/Communist-Manifesto-Releases`
- GitHub：`https://github.com/Lijinzh/Communist-Manifesto-Releases`

两者在视觉和语义上保持同等地位，不使用“主仓库”“镜像”“备用”等主次描述。

首页首屏新增“正式发布与下载”区域，采用两个等宽、同色、同尺寸按钮。当前导航中的“下载”在首页跳转至该区域，首屏下方继续保留较轻量的“了解产品”和“立即购买”入口。首页后续软件下载章节和页脚也同时列出两个仓库。

商城、使用说明和共享页脚的下载相关区域同时提供 Gitee 与 GitHub 链接。所有外部链接继续使用安全的新窗口属性。

## 软件截图替换

发布页面继续只从 `assets/images/` 加载生产素材。实施时复制以下文件并覆盖现有发布素材：

- `figures/main-window-numbered.webp` → `assets/images/software-main.webp`
- `figures/device-settings-numbered.webp` → `assets/images/software-settings.webp`

原始 `figures` 文件夹保留在本地，不整体提交；只提交复制后的两个发布素材。页面中的替代文本、宽高属性按新图片实际尺寸更新。

## 颜色预订规则

商城颜色区域保持灰色为默认选项，并明确：

- 灰色为默认交付颜色。
- 红色、白色、黑色、紫色均只支持提前预订。
- 增加“其他自选颜色”，同样只支持提前预订。
- 任何非灰色方案都需要在闲鱼沟通生产可行性，不承诺现货或固定交付时间。

颜色选择器继续更新当前选择文本和 `aria-pressed` 状态。预订颜色按钮显示“仅预订”提示，自选颜色使用多彩色样并引导用户提交搭配建议。

## 搭配留言区

商城在颜色区域后新增“告诉我们你想要的搭配”版块，说明用户可以建议颜色、麦克风型号、固定方式、使用场景和其他组合；优秀设计可能在后续成为正式版本。

集中反馈链接使用用户提供的腾讯文档：

`https://docs.qq.com/sheet/DQUFjTktqTmF0d1FG?tab=BB08J2`

当前链接是只能查看的普通表格，网站无法直接向其写入数据。因此本轮不伪造站内提交成功状态，也不声称表单已经自动保存。页面以醒目的“前往腾讯文档提交搭配建议”按钮在新标签页打开该链接，并提示实际编辑与保存能力由腾讯文档权限控制。将来用户提供腾讯文档收集表或写入接口时，可在不改变版块结构的情况下替换链接和提交行为。

## 商品图库首图

本轮保留“为 AI 工作流而生的实体界面”顶部现有大图和布局，不进行临时裁切或强行并列。等用户上传新的竖版宣传图后，再将图库调整为与下面三张图协调的四图网格。

建议使用以下 GPT Image 2 指令重新绘制：

> 使用我随后上传的苍虬 ZKO AI 编程手柄产品照片作为唯一外观参考，生成一张高端消费电子电商宣传图。画布为 4:5 竖版，建议 2048×2560；构图与另外三张 4:5 产品功能图协调，产品完整居中，保留真实的灰色机身、四枚侧面红色宏键、彩色小屏、正面灯环、波轮、中键、Type-C 接口和顶部麦克风固定结构，不得重新设计产品造型或增加不存在的按键。背景使用克制的黑色与深灰渐变，加入细微青蓝轮廓光和少量橙色点缀，呈现大疆官网风格的高级工业设计摄影质感，但不得复制大疆页面、Logo、字体或现有广告素材。画面主题是“为 AI 工作流而生的实体界面”，通过简洁的细线标注或图形区域表现实体确认、宏键输入、Agent 状态反馈和小屏信息；中文文字必须准确、少而清晰。如果无法保证文字准确，则只保留干净的文字安全区，不生成任何乱码或伪文字。不要出现人物、手、键盘、电脑桌面、额外麦克风、悬浮零件、水印、品牌混淆或夸张科幻结构。输出应像真实产品棚拍与精致信息图的结合，适合放入四张并列的商城产品图库。

## 测试与验收

自动化测试增加以下合同：

- 三个页面包含 Gitee 和 GitHub 正确链接及安全属性。
- 首页首屏包含同等地位的双仓库入口。
- 新软件图片存在、大小受控，页面尺寸属性与图片实际尺寸一致。
- 商城包含“其他自选颜色”和非灰色仅预订文案。
- 商城包含腾讯文档搭配建议链接，并不包含虚假的站内提交成功文案。
- 现有移动菜单、颜色选择、图片完整性和无障碍测试继续通过。

浏览器验收覆盖桌面与 390px 移动端，确认首屏按钮、颜色区域、腾讯文档入口和新截图不会产生横向溢出或布局破坏。

## 非目标

- 本轮不创建后端数据库或腾讯文档写入 API。
- 本轮不修改腾讯文档权限。
- 本轮不上传或替换新的商品图库宣传图。
- 本轮不把整个 `figures` 文件夹提交到网站仓库。
