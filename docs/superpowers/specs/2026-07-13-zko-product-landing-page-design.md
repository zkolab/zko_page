# 苍虬 AI 编程手柄宣传网站设计

## 目标

为“苍虬 · AI 编程手柄”制作一个可部署到 GitHub Pages 的中文单页宣传网站。网站主要面向已经使用 Codex、Claude Code 等 AI 编程工具的开发者，以及希望尝试语音编程的人群。

网站的核心转化目标是引导访客前往闲鱼商品页，不在页面展示价格。所有购买按钮统一跳转到：

`https://m.tb.cn/h.802lN7o?tk=phNwgK0gm5B`

## 视觉方向

采用已确认的“A · 沉浸式科技产品页”方向：

- 深黑与深蓝作为主背景，以青蓝色光效作为交互和信息强调色。
- 使用大幅产品宣传图形成首屏视觉中心，并延续现有素材的科技硬件气质。
- 标题使用高对比、大字号、短句式排版；正文保持克制，避免把原始长文案整段堆入页面。
- 卡片、细线、微弱辉光和渐变用于建立层次，不使用会影响阅读或性能的重型特效。
- 动效以滚动进入、状态灯呼吸和轻量悬停反馈为主，并尊重系统的“减少动态效果”设置。

## 页面结构

### 1. 顶部导航

展示产品名称或 ZKO 标识，并提供“核心功能”“工作流”“产品参数”和“前往闲鱼购买”入口。移动端收起为简洁菜单或保留关键购买按钮。

### 2. 首屏

主标题为“写代码，不用再低头找快捷键”，副标题说明它是语音编程的确认键和 AI Agent 的状态窗。首屏展示产品主视觉、简短能力标签和主要购买按钮。

### 3. 用户痛点

用三项简短内容说明：键盘输入打断思路、语音输入后仍需找确认键、Agent 运行状态需要切屏查看。该区域用于从真实工作流切入，而不是泛泛介绍硬件参数。

### 4. 核心工作流

用四步流程展示产品价值：

1. 用户说出编程需求。
2. 按实体宏键确认或发送。
3. AI Agent 开始执行。
4. 灯环和小屏反馈当前状态。

### 5. 核心功能

重点呈现以下能力：

- 4 个可编程实体宏键及默认映射。
- Agent 空闲、工作中、等待授权、完成、阻塞等灯效反馈。
- 小屏显示 Profile、蓝牙、电量、时间和设备状态。
- AutoClipboard 上位机的宏键、Profile、灯效、屏幕和固件配置。
- IMU 演讲光圈，用于录课、直播和技术分享。

### 6. 软件与配置

使用现有 AutoClipboard 截图展示桌面端能力，并明确基础蓝牙键盘宏可独立使用，但 Agent 状态灯同步依赖 AutoClipboard 与对应 Agent Hook 配置。

### 7. 产品参数与交付

展示 ESP32、蓝牙与 Type-C、4 个宏键、WS2812 灯环、1.14 寸彩屏、IMU、支持平台、包装清单、测试版路线图和售后保障。路线图功能必须标为计划或测试能力，不能描述为已经稳定交付。

### 8. 页尾转化

使用“把 AI 工作流握在手里”等短句再次总结价值，提供“前往闲鱼购买”按钮和测试版提示。

## 内容原则

- 保留原宣传文案的核心表达，但将长文拆成适合网页浏览的标题、短段落、标签和功能卡片。
- 不展示售价，不制作站内支付、表单、账户或后台。
- 不夸大测试版功能；远程鼠标、快捷调起应用、自定义鼠标宏和更多 Profile 模板只出现在路线图中。
- 大疆麦克风仅为宣传图中的搭配展示，不将其描述为包装内容或产品自带配件。
- 页面语言以中文为主，必要的 Codex、Claude Code、Profile、Agent 等产品和行业词汇保留英文。

## 技术架构

网站使用静态前端实现：

- `index.html`：语义化页面结构和内容。
- `styles.css`：设计系统、响应式布局、动效和无障碍状态。
- `script.js`：移动端导航、轻量滚动效果和集中管理购买链接。
- `assets/`：经过网页优化的产品图和软件截图。

不使用构建工具、服务端、数据库或第三方 JavaScript 框架，确保 GitHub Pages 可直接托管，也便于非开发者后续替换文字、图片和购买链接。

## 数据流与交互

页面加载后直接读取仓库内静态资源。JavaScript 将统一的购买链接赋给所有带购买标记的按钮；点击后在新标签页打开闲鱼页面。导航锚点在当前页面平滑滚动到对应区域。

如果 JavaScript 未加载，HTML 中仍保留有效购买链接和完整正文，核心浏览与购买路径不会失效。

## 异常与降级

- 图片使用明确的宽高、替代文本和延迟加载，单张非关键图片加载失败时不影响正文阅读。
- 首屏关键图不延迟加载，其余宣传图按需加载。
- 外部闲鱼链接不可用时，网站仍能完整展示产品信息；后续只需修改集中配置的链接。
- 关闭 JavaScript、禁用动画或使用较窄屏幕时，页面保持可阅读和可操作。

## 验证标准

- 桌面和手机宽度下没有横向溢出，主要文字和按钮清晰可用。
- 所有购买按钮指向已提供的闲鱼链接，且页面不展示价格。
- 导航锚点、移动端导航和轻量滚动效果按预期工作。
- 所有图片路径有效，关键图片具有合适的替代文本和尺寸声明。
- 页面使用语义化标题层级，键盘可访问，焦点状态可见。
- GitHub Pages 从仓库根目录部署后无需额外构建步骤即可访问。

## 不在本次范围内

- 自定义域名、统计分析、在线客服、站内支付、库存同步和用户信息收集。
- AutoClipboard 软件或手柄固件本身的开发与发布。
- 英文版、多语言切换和动态内容管理系统。
