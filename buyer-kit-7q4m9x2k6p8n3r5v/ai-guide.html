STEP 1

先配置 CC-Switch

CC-Switch 是一个跨平台配置管理器，可以统一管理 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw 等工具的供应商配置。以后换模型时，不必反复手改多个配置文件。

只认准官方入口。项目官方仓库明确声明唯一官网是 ccswitch.io。搜索结果里名称相近的网站、中转平台和推广页面不等于官方软件。
CC-Switch 官方站点 官方 GitHub 官方下载 Releases
  1. 1

    下载对应系统版本

    Windows 用户从 Releases 选择安装程序，macOS 和 Linux 用户选择对应平台文件。不要从网盘或软件下载站获取。

  2. 2

    安装并首次启动

    打开 CC-Switch，确认左侧能看到你准备使用的工具，例如 Codex、Claude Code、Gemini CLI 或 OpenClaw。

  3. 3

    备份现有配置

    如果电脑上已经使用过这些工具，先在 CC-Switch 中查看当前供应商，并使用备份或导出能力保存现状。找不到备份入口时，先不要覆盖原配置。

  4. 4

    添加供应商

    选择目标工具，点击添加供应商或新增配置。优先选择内置官方预设；没有预设时，再按下文填写官方 Base URL。

  5. 5

    填写三个核心字段

    依次填写 Base URL、API Key 和模型名称。模型名必须来自对应官方控制台或文档，不要凭感觉输入。

  6. 6

    测试并切换

    保存后执行连接测试，再点击启用或切换。然后完全关闭并重新打开目标 AI 工具，避免它继续读取旧配置。

成功标志：CC-Switch 显示当前供应商已经启用，目标 AI 工具能返回一条简单回答，并且没有出现 401、余额不足或模型不存在。

STEP 2

获取和保存 API Key

API Key 不是下载文件，而是在模型厂商控制台创建后复制的一串密钥。它通常只完整显示一次，作用接近账户密码。

YOUR_API_KEY_HERE
绝对不要把真实 Key 粘贴到教程、截图、群聊或 GitHub。建议先低额充值或设置消费限额。怀疑泄露时，立即删除旧 Key 并创建新 Key。
  1. 1

    进入官方控制台

    从本页的官方链接进入，不使用搜索广告里的低价密钥网站。

  2. 2

    完成账号要求

    按平台要求登录、实名认证或绑定支付方式；没有余额的 API 通常无法调用。

  3. 3

    创建新 Key

    给 Key 起一个能看懂的名字，例如 zko-cc-switch，创建后立即复制。

  4. 4

    只存到可信位置

    优先使用密码管理器或系统凭据存储；不要保存到会同步或提交的项目文件。

STEP 3

选择一个官方模型供应商

新手只需要先配一个。国内用户建议从 DeepSeek、Kimi、阿里云百炼或火山方舟中选择；有海外网络和支付条件后，再配置 OpenAI、Anthropic Claude 或 Google Gemini。

国内直连推荐入门

DeepSeek

适合先跑通官方 API 和 OpenAI 兼容配置。控制台创建 Key 后，在 CC-Switch 的兼容供应商中填写：

Base URL: https://api.deepseek.com API Key: YOUR_API_KEY_HERE 模型：以官方控制台当前可选模型为准

是否充值：通常需要账户有可用余额。模型名和价格会变化，以官方页面为准。

创建 API Key 官方 API 文档 模型与价格
成功标志：测试请求能返回内容，控制台用量记录出现本次调用。
可能需要科学上网国际支付

OpenAI

适合 Codex 和 OpenAI API。登录官方平台创建 Key，并确认 API 账户有独立的计费或额度；ChatGPT 订阅不等于 API 余额。

Base URL: https://api.openai.com/v1 API Key: YOUR_API_KEY_HERE 模型：以 OpenAI 官方模型页为准
创建 API Key 官方 API 文档 Codex 官方资料
成功标志：OpenAI 平台用量页面出现请求，工具能读取当前目录并回答问题。
可能需要科学上网国际支付

Anthropic Claude

适合 Claude Code。CC-Switch 有官方或 Anthropic 预设时优先使用预设，不要随意更改接口格式。

Base URL: https://api.anthropic.com API Key: YOUR_API_KEY_HERE 模型：以 Anthropic Console 当前可用模型为准
创建 API Key 官方 API 文档 Claude Code 文档
成功标志：Claude Code 启动后不再要求重新登录，并能回答当前项目的问题。
可能需要科学上网可有免费额度

Google Gemini

适合 Gemini CLI。最简单的方式是在 Google AI Studio 创建 Key，再使用 CC-Switch 的 Gemini CLI 预设。

API Key: YOUR_API_KEY_HERE 模型：以 Google AI Studio 当前可用模型为准 Base URL：优先保留 CC-Switch 官方预设
创建 API Key API Key 官方文档 Gemini CLI 官方仓库
成功标志：Gemini CLI 能启动并对当前目录给出简短说明。
国内直连中文友好

Kimi / Moonshot AI

适合国内用户接入长文本和编程模型。使用 Moonshot 开放平台创建 Key，优先选择 CC-Switch 内置 Kimi/Moonshot 预设。

Base URL: https://api.moonshot.cn/v1 API Key: YOUR_API_KEY_HERE 模型：以 Moonshot 控制台当前可选模型为准
创建 API Key 开放平台文档
成功标志：控制台出现调用记录，AI 工具能正常返回中文内容。
国内直连企业云平台

通义千问 / 阿里云百炼

适合已有阿里云账号的用户。先在百炼开通模型服务并创建 API Key，再选择 OpenAI 兼容模式。

Base URL: https://dashscope.aliyuncs.com/compatible-mode/v1 API Key: YOUR_API_KEY_HERE 模型：以百炼控制台当前开通模型为准
百炼控制台 千问首次 API 调用
成功标志：百炼监控中出现调用，返回内容没有“模型未开通”提示。
国内直连需要创建推理接入点

豆包 / 火山方舟

火山方舟通常需要先开通模型并创建推理接入点。配置时使用控制台提供的接入点 ID，不要把展示名称当作模型名。

Base URL: https://ark.cn-beijing.volces.com/api/v3 API Key: YOUR_API_KEY_HERE 模型：填写方舟控制台创建的推理接入点 ID
方舟 API Key 方舟 API 文档
成功标志：接入点状态正常，测试请求有返回并产生用量记录。
第三方中转不是默认方案。它可能更便宜或更容易访问，但存在模型替换、日志留存、余额和停服风险。即使 CC-Switch 页面出现赞助商，也不代表它是模型厂商的官方 API。

STEP 5

开始你的第一个工作

第一次不要让 AI 直接改代码。先验证它是否真的理解项目，再让它完成一个小任务。

第一句话：只读了解项目

请先阅读当前文件夹中的 README.md 和项目文件，不要修改任何内容。用简单中文告诉我：这个项目做什么、怎么运行、我可以先完成哪一个最小任务。
成功标志：AI 能说出真实存在的文件和运行命令，并明确表示尚未修改文件。

第二句话：计划后再动手

请在修改前先列出计划。每完成一步就运行对应检查；如果失败，先解释原因，不要连续尝试高风险命令。
成功标志：AI 先给出少量步骤，说明会修改哪些文件和怎样验证，而不是立刻进行大范围改动。

第三句话：完成后核对

请运行与本次修改相关的测试或检查，然后列出：修改了什么、验证结果、仍有哪些限制。没有验证证据时不要说已经完成。

QUICK FIXES

连接失败时先看这里

出现 401、Invalid API Key 或 Unauthorized
确认 Key 来自对应官方平台、复制时没有多余空格、CC-Switch 已启用正确供应商。仍失败就删除旧 Key 并重新创建；不要把真实 Key 发给别人排查。
提示余额不足、额度不足或 Billing Error
进入官方控制台查看 API 余额和计费状态。聊天产品订阅通常不等于 API 额度，必须以 API 控制台显示为准。
提示模型不存在或没有权限
从官方控制台复制当前可用模型名。火山方舟要检查推理接入点 ID；百炼要确认模型已经开通；不要继续使用已经下线的旧模型名。
CC-Switch 显示已切换，但工具仍用旧配置
完全退出目标工具后重新打开。检查 CC-Switch 当前选择的工具是否正确，并确认没有另一个环境变量或项目配置覆盖全局配置。
连接超时或国内无法访问
先用浏览器打开对应官方控制台确认网络是否可用。国内基础路线优先使用 DeepSeek、Kimi、百炼或方舟；海外平台可能需要科学上网。不要通过来历不明的代理页面输入官方 Key。
改错配置后工具无法启动
使用 CC-Switch 切回原供应商或恢复之前的备份。没有备份时，先查看工具官方配置说明，不要盲目删除整个配置目录。
