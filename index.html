保持专注

别让一次操作打断正在成形的思路

  • 打字让思路中断

    需求已经想清楚，却要从表达切回键盘输入，脑中的上下文随动作被切碎。

  • 语音后还要找确认键

    说完需求又低头寻找 Enter，顺畅的语音输入在最后一步卡住。

  • 切屏查看 Agent

    频繁切换窗口，只为确认 Agent 正在工作、等待授权，还是已经完成。

四步闭环

从一句话，到清晰可见的执行反馈

  1. 说出需求保持自然表达，把注意力放在目标和上下文上。
  2. 实体键确认按下手柄上的确认键，无需低头寻找键盘。
  3. Agent 工作Codex 或 Claude Code 接收任务并持续执行。
  4. 灯环与小屏反馈用颜色和文字快速了解当前状态。

1.14 英寸彩色屏幕

集中显示 Profile、BLE 连接、Agent 状态、电量、时间和设备状态，也支持自定义图标，让当前模式一眼可辨。

AutoClipboard 自定义

按个人工作流自定义 4 枚宏按键、切换与配置 Profile，并调整屏幕、灯环、蜂鸣器和设备连接，让手柄适配不同项目和工具。

IMU 演示聚光灯

内置 IMU 当前用于演示聚光灯和姿态预览，适合录课、直播与技术分享。它是虚拟激光笔式的演示辅助工具，并非高精度鼠标的替代品。

软件协同

AutoClipboard 把手柄融入你的工作流

在桌面端查看连接与状态、调整按键映射，并为不同工具组织配置。基础 BLE 键盘宏可脱离软件独立使用；Agent 状态同步则需要运行 AutoClipboard，并完成 Codex 或 Claude Hook 配置。

  • 自定义 4 枚宏按键，切换与配置 Profile
  • 设置自定义屏幕图标、屏幕亮度与显示模式
  • 调整灯环亮度与主题色，以及蜂鸣器音量
  • 查看 BLE、电量与设备状态，并清除蓝牙配对
  • 检查软件更新，并通过 Type-C 完成固件更新
