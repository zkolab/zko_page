QUICK START

5 分钟完成首次使用

  1. 1

    下载 AutoClipboard

    Windows 是当前主要支持平台。前往 GitHub 下载仓库选择与你系统相符的安装包。

  2. 2

    先给手柄充电

    使用 USB Type-C 线连接。串口诊断和固件更新必须使用支持数据传输的线。

  3. 3

    打开或唤醒手柄

    全新设备或已清除配对的设备会开放约 120 秒蓝牙配对窗口。

  4. 4

    连接 CommunistKB-XXXX

    在电脑蓝牙设置中选择扫描到的完整名称，末尾编号不需要手动输入。

  5. 5

    运行软件并测试

    让 AutoClipboard 在后台运行，拨动波轮切换 Profile，按一下宏键，再双击中键进入 Settings。

BLUETOOTH

第一次蓝牙配对

当前固件的蓝牙广播名称固定为 CommunistKB-XXXX。XXXX 是设备自动生成的四位编号，已经包含在完整名称中。

PAIR临时开放，可添加新的蓝牙主机
LINK已经连接当前选择的电脑
WAIT等待已保存的电脑重新连接
  1. 打开 Windows、Linux 或 macOS 蓝牙设置，选择添加设备。
  2. 打开或唤醒手柄，等待小屏显示 PAIR。
  3. 在电脑上选择完整的 CommunistKB-XXXX。
  4. 配对并连接后，小屏显示 LINK。

MULTI HOST

保存和切换 3 个主机槽位

  1. 双击波轮中键进入 Settings。
  2. 拨动到 BLE Hosts，单击进入。
  3. 选择一个 EMPTY 空槽位并单击。
  4. 看到 PAIR 后，在新电脑的蓝牙设置中添加 CommunistKB-XXXX。

手柄可以保存 3 个主机槽位。在 BLE Hosts 中，单击已有槽位切换电脑，长按已有槽位删除该主机记录。

CONTROLS

波轮、中键与 4 枚宏按键

操作正常状态页Settings
向上或向下拨动切换 Profile移动选项或调整数值
单击中键打开 Profile 绑定的应用、快捷方式或网页进入、编辑、确认或保存
双击中键进入 Settings—
长按中键进入 Settings取消、返回或退出

不要尝试按住中键同时拨动波轮；机械结构不支持这种组合动作。

AUTOCLIPBOARD

基础宏可独立使用，深度能力需要软件

AutoClipboard 可以配置 Profile 名称和图标、录制宏按键、调整小屏、灯环和蜂鸣器、查看 IMU 三维姿态、配置演讲光圈，并在受控流程中更新固件。

Agent 状态同步、Profile 快开、IMU 预览或演讲光圈需要 AutoClipboard 保持后台运行。基础蓝牙键盘宏不依赖软件。

TROUBLESHOOTING

常见问题

系统里找不到 CommunistKB-XXXX

唤醒手柄，进入 Settings > BLE Hosts，选择 EMPTY，等小屏出现 PAIR 后重新扫描。

已经配对，但 AutoClipboard 没有就绪

保持手柄唤醒，启动 AutoClipboard，再检查蓝牙设备与软件状态。

宏按键能用，但没有 Agent 状态

说明蓝牙键盘连接正常；还需要配置 Agent Hook/Bridge，并保持 AutoClipboard 运行。

Type-C 连接后没有 COM 端口

更换支持数据传输的线和 USB 接口，并从下载仓库安装 CH343 驱动。

软件提示更新固件

先确认设备板型与更新方案，再执行固件更新。不要刷入不对应的固件包。
